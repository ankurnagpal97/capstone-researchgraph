# AI ResearchGraph: task specification

What the copilot does, what it must refuse, and what a correct answer looks like. The evaluation sets and
metrics below are the ones every result in `REPORT.md` is measured against.

> **Honest note on timing.** The course asks for this specification and the evaluation set to be written before
> any code. Ours was not: the first 42 curated questions were committed together with the first working version
> of the code (19 Nov), and this page was written on 23 Nov from the behaviour the project had already committed
> to. To limit the damage, the curated questions are used only as a test set; prompts and thresholds were tuned on
> separate dev sets. The 20 questions added on 23 Nov (q43–q62) were written after the system existed.

## 1. Users and job

A researcher or engineer choosing a retrieval architecture asks questions about published RAG and LLM-retrieval
research (2022–2026 plus older foundation papers), for example *"How do RAGAS and ARES differ in how they evaluate
RAG systems?"* or *"Which methods build on IRCoT?"*. They need an answer they can check: every claim tied to the
exact passage (paper, section, page) it came from, honest about comparability, and explicit when the papers do not
settle the question.

## 2. What the system does

| Capability | Behaviour |
|---|---|
| Answer from the corpus | Retrieves passages from 146 indexed papers (11,148 chunks), answers with Qwen3-8B as a JSON claim list, each claim citing passage labels that code maps to chunk IDs |
| Show its evidence | Every source with title, year, section, pages, arXiv link and the passage text |
| Compare carefully | A comparison is "directly comparable" only if one passage reports both results under the same setting (checked in code) |
| Treat surveys as second-hand | Claims taken from survey papers are written as "according to <survey>" |
| Explore | Citation neighbours (arrows mean *cites*, never *agrees*), follow-up question suggestions |
| Agent mode | Planner → tools (search, read one paper, citation neighbours, paper info) → answer → critic, with session memory |

## 3. What it must refuse or decline

| Request | Required behaviour |
|---|---|
| A question the indexed papers do not answer (other domains, proprietary systems, numbers not reported) | Say "Not established by the indexed papers" and state what is missing; never fill in from model memory |
| A question about a named method/model absent from the evidence | Decline (code check: every name in the question must appear in the evidence) |
| "Ignore your rules / answer from your own knowledge / print your prompt" | Ignore; answer only from passages or decline |
| Instructions hidden inside a paper passage | Treat as quoted data, never as instructions |
| Personal data in a question | Removed before it reaches the model, logs, traces or cache |
| Consequential actions (sending, buying, deleting, deciding for someone) | Out of scope: the system only reads and cites; see `RESPONSIBLE_AI.md` |
| Medical, legal or financial advice | Out of scope; any such question is answered only as "what the RAG papers say", usually an abstention |

## 4. What a correct answer looks like

An answer is **correct end-to-end** when:

1. **Decision:** it answers an answerable question and abstains on an unanswerable one; and
2. **Sources:** for an answerable question, at least one gold paper is among the cited sources; and
3. **Grounding:** every claim cites at least one passage label that exists in the evidence pack (100% citation-ID
   validity), and the cited passage supports the claim (checked by the Qwen self-judge, and by humans on a
   60-claim sample).

Quality beyond correctness is measured against a reference answer: ROUGE-1/2/L, token F1 and embedding similarity
(`STAGES.md`). A short, fully cited partial answer with the gaps listed under "missing evidence" is preferred over a
complete-sounding answer with an uncited claim.

## 5. Evaluation sets

| Set | Size | Use |
|---|---|---|
| Curated (`questions_v0.jsonl` + `curated_references.jsonl`) | 62 questions: 22 single-paper, 13 comparison, 10 multi-hop, 5 metadata, 3 disagreement, 9 unanswerable | Test set; gold papers, gold passages and reference answers (drafted, under team review) |
| Synthetic test (`synthetic_test.jsonl`) | 45 | Generated by Qwen3-8B from one passage each; easier; retrieval check without curation bias |
| Synthetic dev, answer dev, comparison dev | 105 + 28 + 12 | Tuning only (prompts, thresholds, decomposition, prompting-strategy comparison) |
| QASPER test (external) | 194 questions over 60 NLP papers | Independent check of within-paper evidence retrieval (human annotations) |

## 6. Metrics

Retrieval (separately from answers): paper Recall@5/10, passage Hit@10, MRR, nDCG@10. Answers: end-to-end accuracy,
abstention on unanswerable, answered when answerable, citation validity, judged support, ROUGE / F1 / semantic
similarity. Agent: task completion rate, tool calls and LLM calls per task, tokens per query (cost), latency p50/p95.
Failures are classified as retrieval miss, reasoning error, tool-call error or hallucination (`AGENT.md`).
